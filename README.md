
# Digital Design & FPGA Flow Training

This repository contains the tasks, resources, and project for the training program.

## Repository Contents

###  Assignments

Tasks required to be submitted **after the session**.

###  Labs

Tasks required to be completed and submitted **during the session**.

###  Important Links

Useful links, websites, documentation, and **open-source tools** related to Digital Design and FPGA Flow.

###  Project

**4×4 Crossbar Packet Switch with UART Driver**

The final project focuses on designing and implementing a **4×4 crossbar packet switch** with a **UART-driven interface**, applying the digital design and FPGA flow concepts covered throughout the training.
